# Three.js Car Dodger

A simple 2D-style car dodging game built with Three.js and Vite.

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in your browser.

## Controls

- **Left / A**: Move left
- **Right / D**: Move right
- **R** or **Space**: Restart after a crash

## Build

```bash
npm run build
```
