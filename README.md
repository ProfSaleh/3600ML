# Three.js 2D Car Dodging Game

A simple lane-based dodging game built with **three.js**.

## How to run

1. Start a local web server from this folder:
   - `python3 -m http.server 8000`
2. Open `http://localhost:8000` in your browser.

## Controls

- `A` / `D`
- `Left Arrow` / `Right Arrow`

Switch lanes to avoid incoming cars.  
After a crash, press **Enter** or click **Play Again** to restart.
