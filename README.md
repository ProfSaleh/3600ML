# AgenticU: Vibe Coding to Agentic Engineering

An interactive educational app for undergraduate students learning how AI-assisted software development changes from casual "vibe coding" into disciplined, verifiable agentic engineering.

## What students learn

- How the workflow spectrum moves from trial-and-error prompting to production-grade verification.
- Why context engineering matters more than clever one-off prompts.
- How instructions, knowledge, memory, examples, tools, and guardrails shape agent behavior.
- What the factory model means for modern developers, including conductor and orchestrator modes.
- How to rewrite vague prompts into engineering briefs with specifications, tests, and guardrails.

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in your browser.

## Build

```bash
npm run build
```
